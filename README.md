# Dashboard Project

## Structure
- `index.html` - Main dashboard page
- `styles.css` - Styling
- `scripts.js` - JavaScript logic
- `data/` - Data files

## Setup
1. Create a new GitHub repository
2. Enable GitHub Pages (https://<username>.github.io/<repo-name>/)
3. Add a `.gitignore` file to exclude generated files

## Workflow
- Edit files in `/dashboard-project/`
- Commit changes
- Push to GitHub
- Watch GitHub Pages auto-deploy
